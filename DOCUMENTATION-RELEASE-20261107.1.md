# CALF Extensions documentation revision docs.1 · preview

The reviewed English and Korean guides are now included inside the download packages, including offline HTML manuals and Navigator PDFs. Agent terminology, setup wording and companion-document links have been corrected.

Harness 1.8.8, Workbench 1.9.3, SDK 0.2.2 and the host adapters keep their existing runtime code. The native package manifest now matches the updater’s four-field contract; local update preparation passes on macOS ARM64, Windows x64 and Debian x64. SDK tests (16 per OS), Repository install/version rollback and fresh Navigator qualification also pass on all three.

Extract into a new folder and keep the complete existing records home, contracts, settings, runtimes and old tool paths. This documentation revision is a manual download; automatic version discovery does not treat it as a runtime upgrade. Previous releases remain available.

Managed Repository, Navigator and Video packs use `+docs.1` identities so the old version’s bytes and locks remain valid. Qualify the new candidate before explicitly selecting it. Preview status and the original media/provider qualification limits are unchanged. No new AI-service or long-duration claim is made.

## 한국어

교정한 영·한 안내를 배포 패키지 안에도 반영했습니다. 오프라인 HTML 매뉴얼과 Navigator PDF를 함께 맞추고, 에이전트를 세는 표현·설치 문장·외부 참고 링크를 정리했습니다.

하네스 1.8.8·워크벤치 1.9.3·SDK 0.2.2·호스트 어댑터의 실행 코드는 그대로입니다. 네이티브 패키지의 매니페스트 형식은 업데이터 규약에 맞췄으며, macOS ARM64·Windows x64·Debian x64에서 업데이트 준비가 통과했습니다. SDK 검사(운영체제별 16개), Repository 설치·버전 복귀, Navigator 신규 검수도 세 환경에서 통과했습니다.

새 폴더에 압축을 풀고 기존 기록 전체·계약·설정·runtimes와 이전 도구 경로를 보존하세요. 이번 문서 개정판은 직접 다운로드하며, 자동 업데이트에서는 새 실행기 버전으로 표시하지 않습니다. 이전 릴리즈도 계속 받을 수 있습니다.

관리 대상인 Repository·Navigator·영상 팩에는 `+docs.1` 식별자를 사용했습니다. 기존 버전과 잠금 정보는 유지하고, 새 후보를 검수한 뒤 직접 선택하세요. 프리뷰 상태와 기존 미디어·프로바이더 검증 범위는 그대로입니다. 이번에 AI 유료 호출이나 장시간 시험을 새로 수행한 것은 아닙니다.
