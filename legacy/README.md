# Historical implementations

Only the native FFmpeg extension in the root catalogue is part of the current extension distribution. Repository Intelligence has moved into the CALF core. Navigator, Video Work Management, motion experiments and the earlier Python pack/repository/media implementations are retained as historical material, not active packages. Earlier releases, source history and user records are preserved.

The archived `python/pyproject.toml` documents the earlier package; it is not an installation entry point from this directory. Do not install a second legacy Repository route over a current native CALF connection.

현재 확장 배포에는 루트 목록의 Rust FFmpeg 확장만 포함합니다. Repository Intelligence는 CALF 코어로 옮겼습니다. Navigator·Video Work Management·모션 실험과 이전 Python 구현은 과거 자료로 보존하며, 현재 설치 대상으로 안내하지 않습니다. 과거 릴리즈·소스 이력·사용자 기록도 유지합니다. 기존 연결 위에 이전 Repository 경로를 중복 설치하지 마세요.
